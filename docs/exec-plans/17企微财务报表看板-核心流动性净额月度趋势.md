# 17企微财务报表看板：核心流动性净额月度趋势

## 目标

在“资产净额分析”增加与主营业务毛利图同风格的黑底霓虹月度趋势图，仅展示核心流动性净额。

## 数据口径

- 年份取当前会计期间年份。
- 每月读取该公司当月已发布的科目余额表。
- 核心流动性净额＝货币资金＋内部往来净额，沿用当前资产净额分析的计算逻辑。
- 没有已发布科目余额表的月份标记为无数据并在折线中留空，不虚构为零。

## 实施范围

1. 后端资产净额分析接口返回 12 个月的 `monthlyTrend`。
2. 前端增加单线霓虹趋势图及金额标注。
3. 趋势图作为 `core_liquidity_trend` 纳入管理员分析板块拖动排序。
4. 增加接口、布局和前端静态回归测试，更新版本与 README。

## 验证

- `npm run check`
- `node --check public/app.js`
- `npm test`
- 本地 3182 页面检查标题、12 个月横轴、真实非零月份金额、无数据月份留空、拖动手柄及手机端横向可读性。

## 回滚

移除 `monthlyTrend` 组装、`core_liquidity_trend` 默认板块、趋势图渲染和对应样式/测试；不修改现有报表或上传数据。
