# 企业微信授权到期检测与安全续权实施计划

## 目标

在保持财务看板企业微信 CLI、凭证和 systemd 单元完全独立的前提下，自动检测约 7 天失效的授权。授权失效时仅向财务管理员弹出当次有效的重新授权链接；管理员完成企业微信确认后，系统自动复检授权、刷新脱敏顾问目录并恢复常规定时同步。不得复制或调用出纳小W的配置，也不得扩大花名册字段读取范围。

## 安全边界

- CLI 固定为 `/opt/wecom-finance/wecom-cli`，凭证固定为 `/var/lib/wecom-finance-cli`，不安装到全局 PATH，不复用 `/root` 或其他机器人的凭证。
- 花名册仅按企业微信 CLI 1.2.0 的结构化精确区域接口读取姓名和英文名两列；若响应列数超过 2，立即停止且不覆盖上一份安全快照。
- 授权链接必须是临时的 `https://work.weixin.qq.com/` 地址，服务端只保存短期状态，不保存二维码、令牌、Cookie 或授权回包。
- 授权链接只返回给财务管理员；普通顾问分析用户只看到“请联系管理员更新授权”。
- 自动化只负责检测和生成授权入口，不代替管理员点击企业微信确认，不尝试绕过授权有效期。
- 仅启用 `wecom-finance-consultant-*` 单元，不修改小Q、小W、其他项目服务、数据卷或环境变量。

## 验收标准

- 授权有效时不显示提示；失效后一个检测周期内仅管理员看到重新授权弹窗和有效链接。
- 普通用户、无顾问模块权限用户和未登录请求均不能读取或生成授权链接。
- 链接过期或授权流程退出后可重新生成，且同一时刻最多存在一个授权进程。
- 授权成功后不需要服务器手工命令即可触发一次目录同步；同步成功后弹窗消失。
- 顾问快照人员对象仍仅含 `name`、`englishName`、`employmentStatus`，文件 `0600`、目录 `0700`。
- 生产财务容器、数据库计数和其他项目服务在部署前后保持正常。

## 回滚

先停用新增授权 path/service，再停用顾问目录 path/timer，恢复上一镜像和上一版财务 systemd 文件；保留独立 CLI 与凭证不会影响旧版应用。若需彻底撤销，仅删除财务专用 drop-in、`/opt/wecom-finance/wecom-cli` 和 `/var/lib/wecom-finance-cli`，不得触碰其他机器人目录。
