# 主营业务分析模块

## 目标

在现有财务看板中新增只读的“主营业务分析”模块，使用上传的序时账作为唯一事实源，展示本期项目收入成本明细、项目数量环比和本年毛利月度趋势，并由模块权限控制导航和接口访问。

## 数据口径

- 主营业务收入按科目名称 `主营业务收入-` 识别，取贷方金额。
- 主营业务成本按科目名称 `主营业务成本-` 识别，取借方金额。
- 合同编号优先从摘要/备注提取 `20YYYYMM-####`，提取不到时记为“未识别合同”。
- 项目名称优先使用原始“项目名称”列；为空时取主营业务科目名称去掉一级前缀后的内容。
- 本期/上期项目数量按自然月内的唯一合同编号计数；上期为上一个自然月。
- 毛利为收入减成本，毛利率为毛利除以收入；收入为 0 时显示空值。

## 实现范围

1. 新增 `main_business_analysis` 模块、权限和全局排序项，默认管理员与财务负责人可见。
2. 新增 `/api/analysis/main-business`，返回明细、项目归类、年度月度趋势、来源和数据警告。
3. 新增前端分析页面：明细表、项目数量变化表及横向图、本年毛利科技感 SVG 趋势图。
4. 增加无数据、来源说明、权限隔离和聚合口径测试；版本递增并在本地预览验证。

## 验证

```powershell
npm run check
node --check public/app.js
npm test
```

本地预览使用 `http://127.0.0.1:3182/`，切换到管理员并选择有序时账数据的期间查看模块。
