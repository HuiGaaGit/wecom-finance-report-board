# 分析板块拖动排序

## 目标

让管理员可在现金流分析、主营业务分析、费用分析页面直接拖动各个指标卡、表格和图表板块，并将三个页面的顺序分别保存为全局布局；其他员工只读取布局，不显示拖动控件。

## 实现范围

1. 新增分析板块排序表，按分析页面和板块键保存全局顺序，并为旧数据库补齐默认顺序。
2. 在启动接口返回三个分析页面的板块顺序；新增管理员保存接口，严格校验页面、板块集合和权限。
3. 三个分析页面改为统一的十二列布局，每个可移动板块具备稳定键和宽度；管理员看到拖动手柄，普通员工保持只读。
4. 拖动结束后立即保存，失败时提示并重新渲染服务端顺序。
5. 补充权限、顺序持久化和板块集合回归测试，递增版本并做浏览器验证。

## 默认板块

- 现金流分析：五个资金指标、构成关系、资金口径、应收应付净额构成、现金流量结构、货币资金账户、其他流动项目。
- 主营业务分析：数据来源、四个指标、本月项目收入成本、项目数量变化、年度毛利趋势。
- 费用分析：数据来源，以及销售、管理、财务费用的表格、占比和趋势/支付方式板块。

## 验证

```powershell
npm run check
node --check public/app.js
npm test
```

浏览器以管理员身份分别打开三个分析页面，拖动首个板块并刷新确认顺序持久化；切换普通员工确认不显示拖动手柄。
