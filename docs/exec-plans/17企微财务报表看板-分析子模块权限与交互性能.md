# 分析子模块权限与交互性能

## 目标

将资产净额、主营业务和费用分析中用户标注的子模块纳入所属页面下的独立查看权限；管理员保存的全局分析布局跨版本升级保持不变；同时降低报表切换与子模块拖动换位时的卡顿。

## 实现范围

1. 集中定义三类分析页面的受控子模块和权限键，扩展权限目录、角色默认权限、旧档案迁移、父子权限约束和启动接口可见性。
2. 分析接口按员工权限裁剪对应子模块数据，前端在布局、折叠和拖动绑定之前移除无权板块，避免仅靠样式隐藏。
3. 分析布局以数据库为持久事实源，启动时只追加新板块并保留已有相对顺序；保存时始终维护完整顺序，避免受限可见集合覆盖管理员全局布局。
4. 优化页面切换的请求与到场动画，避免同步强制回流和过期响应覆盖；使用动画帧合并拖动换位，减少重复测量和动画重启，并保留轻微回弹。
5. 补充权限隔离、父子权限、布局升级持久化、快速切页和拖动静态契约测试；递增版本、更新说明并构建新发布包。

## 验证

```powershell
node --check app.mjs
node --check public\app.js
npm test
npm run check:deploy
npm run build:release
```

浏览器以管理员和受限员工分别验证权限树、各分析页面可见板块、布局刷新/重启保留、快速切页与桌面/手机拖动交互，并检查控制台错误和横向溢出。

- 权限中心的经营分析分类现为 `24/24`，其中资产净额、主营业务和费用分析共 16 个标注子模块均可独立授权；父页面权限与子权限在前后端同时约束。
