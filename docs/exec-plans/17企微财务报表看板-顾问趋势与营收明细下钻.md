# 顾问趋势与营收明细下钻

## 目标

在集团“顾问投入产出比”模块中提供两类只读下钻：点击顾问姓名查看所选年度截至当前期间的预计营收与投入产出比双轴趋势；点击预计营收金额查看该顾问当前期间的合同级营收明细。

## 数据与权限边界

- 趋势只查询当前员工拥有顾问投入产出模块权限的月份，并且只返回单个可见顾问的月度汇总。
- 月份以已发布且可解析的集团营收统计表为准。整月未发布不展示；已发布但该顾问无营收显示 0；投入为 0 时 ROI 返回空值。
- 历史 ROI 复用各月管理员已保存的投入项目及报销二级科目设置，未配置月份沿用该月默认口径。
- 营收明细只返回合同编号、项目名称、客户名称和预计营收额，不返回营收表整行、工资、报销或其他敏感字段。
- 管理员隐藏的顾问不可通过构造请求下钻；接口先校验集团、期间、模块权限和当前可见顾问。
