# 17企微财务报表看板：应收应付净额构成展开

## 目标

精简资产净额分析的“应收应付净额构成”表：说明默认收进小问号，点击后再展示；表格右侧按需展开应收账款、其他应收款、应付账款、其他应付款四类净额构成。

## 交互与口径

- 每行说明使用可点击的 `?`，不再长期占用宽列。
- “展开净额构成”按钮控制四个构成列整体显示或收起，展开方向保持在原表右侧。
- 应收类按资产余额显示，应付类按负债余额显示；期末净额仍按“应收账款＋其他应收款－应付账款－其他应付款”计算。
- 零值构成显示为短横线，避免把无数据误读为实际余额零。

## 实施范围

1. 前端整理每行四类构成数据并增加展开控制。
2. 增加问号说明弹层、展开按钮和横向宽表样式。
3. 增加静态回归测试并更新 README。
