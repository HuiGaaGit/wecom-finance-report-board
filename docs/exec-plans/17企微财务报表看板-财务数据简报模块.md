# 财务数据简报模块实施计划

## 目标

在左侧“财务报表”分组中新增“财务数据简报”，默认排在“资产负债表”之前。用户选择公司和会计期间后，简报按当前范围自动读取该月已发布报表，并生成“YYYY年M月收支部分明细”文字说明；不新增人工录数入口，也不复制或固化金额。

## 取数口径

- 预计营收：所选期间“（营收利润口径）合并利润表”中集团或对应公司分表的“当月营收利润”值。
- 账户余额：公司取资产负债表“货币资金”期末余额；集团汇总同期间各子公司资产负债表“货币资金”期末余额。
- 营业收入、营业成本、销售费用、管理费用、财务费用、净利润：公司取同期间利润表本期金额；集团取“桉侨集团合并利润表”本期金额。
- 其中广宣费：公司从同期间科目余额表/序时账中归集销售费用下的“广宣费、广告费、业务宣传费”等宣传类二级科目；集团加总各子公司同口径金额。销售费用总额仍直接取利润表，不用广宣费反算。
- 营收综合利润：所选期间“（营收利润口径）合并利润表”中集团或对应公司分表“净利润”本期金额。
- 只读取当前发布版本。来源缺失时该项显示短横线并列出缺少的报表，不把缺失值当作 0。

## 权限与范围

- 新增独立“财务数据简报 · 浏览”权限，纳入经营分析权限树和既有角色预设。
- 既有员工如已有资产负债表、利润表或集团合并利润表浏览权限，则一次性迁移获得简报浏览权限；仍受其公司与期间范围限制。
- 集团简报只展示集团聚合值；公司简报只展示当前公司值。接口不返回其他未授权公司的逐家公司金额。

## 实施步骤

1. 增加模块注册、默认顺序、权限节点、角色默认值和既有员工权限迁移。
2. 后端增加简报聚合器，读取已发布原始报表，兼容集团主表、集团子公司分表及公司单体报表。
3. 增加只读简报接口，返回指标、来源文件、完整性状态和缺失项。
4. 前端增加简报页面，按用户给定话术生成响应式文字排版，并在金额下方展示数据来源与缺失提示。
5. 补充接口取数、权限、导航顺序、缺失数据和前端静态回归测试。
6. 首次交付版本从 `1.0.96` 递增到 `1.0.97`；首页入口修正版本递增到 `1.0.98`，同步源码、UI、README 和发布包文件名事实源。

## 验证标准

- “财务数据简报”默认位于“资产负债表”之前，管理员仍可拖动调整全局顺序。
- 首页“开始浏览报表”只从当前可见的财务数据简报和报表类型中选择首个模块；默认进入简报，无简报权限时回退到首个可见报表，不进入上传、分析或管理模块。
- 2026 年 7 月集团简报的营业收入、营业成本、三项期间费用、净利润分别与集团合并利润表本期金额一致；预计营收和营收综合利润与营收利润口径文件一致。
- 公司范围可匹配营收利润口径集团文件中的对应公司分表，并与本公司资产负债表、利润表联合取数。
- 任一来源未上传时页面明确标注缺失，不使用演示模板或其他期间数据。
- 无简报权限或超出公司/期间范围时接口返回 403。
- `node --check app.mjs`、`node --check public/app.js`、`npm test`、`npm run check:deploy` 全部通过。
