# 顾问投流消耗费用数据源实施计划

## 目标

在桉侨集团“顾问投入产出比”模块中，把每月上传的“顾问消耗-营收表”作为分析专用数据源。系统只读取“汇总”工作表，按顾问英文名唯一匹配“总消耗/元”，在“人员费用”右侧展示“投流消耗费用”，并纳入标签、投入合计、投入产出比、筛选、排序及导出。

## 数据契约

- 上传范围固定为桉侨集团和所选会计期间。
- 工作表通过名称“汇总”和表头语义共同识别，不依赖固定行列。
- 顾问英文名优先读取明确的“英文名/顾问英文名”表头；对于样例中的合并表头“顾问”，取合并区域的末列作为英文名列。
- 投流费用读取“总消耗/元”或“总消耗”列。
- 地区用于来源诊断；“市场部分给渠道部”、合计、汇总等非顾问行不参与匹配。
- 英文名忽略大小写、空格和常见标点；只有唯一匹配才入账，重名或无法匹配的记录保留为异常统计，不猜配。
- 原文件为分析专用敏感数据源，不提供通用 raw、summary、detail、versions 或 export 整表接口。

## 验收标准

- 样例“汇总”表可识别英文名和“总消耗/元”，不读取其他工作表或汇总行。
- 英文名大小写差异可匹配；歧义名和未匹配名不计入任何顾问。
- 关闭“投流消耗费用”标签时整列隐藏且投入合计、投入产出比同步重算。
- 桌面端表格保持模块内完整铺开，窄屏仅在表格内部滚动。
- 完整自动化测试、语法检查、部署配置检查和差异检查全部通过。

## 回滚

本次不修改数据库结构。回滚时切回上一镜像即可；新上传批次仍保留在通用上传表中，旧版本不会读取新增报表类型。生产切换前必须按既有运维流程创建 SQLite 一致性备份。
