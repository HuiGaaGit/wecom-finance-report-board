# 17企微财务报表看板：企微通讯录同步修复 ExecPlan

## 目标

修复生产权限管理页只能搜索到已登录员工、却错误显示“已同步”的问题。应用应使用自建应用凭证读取其企微可见范围内的通讯录成员，写入本地员工目录，并允许管理员搜索、授权和复制权限。

## 已确认原因

- 当前 OAuth 回调只同步本次登录员工本人。
- 权限管理页的搜索接口只查询本地 `employees` 表，没有调用企微通讯录接口。
- 页面无条件显示“已同步”，无法反映企微接口权限、可见范围或同步失败。

## 实施步骤

1. 为员工记录补充通讯录来源和同步时间，并增加通讯录同步状态表。
2. 生产模式调用企微部门与成员接口，将应用可见范围内员工幂等写入本地库；设置短时缓存并避免并发重复同步。
3. 权限页打开时自动同步，搜索时使用同步后的员工目录；提供准确的成功、失败和本地演示状态，以及管理员手动刷新入口。
4. 增加模拟企微接口的生产模式集成测试，覆盖 OAuth、全量目录同步、部门名称映射和按姓名搜索。
5. 为已添加员工提供“移除授权”，只清除本应用角色、个人微调和数据范围，不删除企微通讯录人员；禁止管理员移除自己。
6. 版本递增，更新部署说明，完成本地验证、构建和生产发布。

## 验证标准

- 生产权限管理页可搜索尚未登录过应用、但位于应用可见范围内的企微员工。
- 同步失败时不再显示“已同步”，并给出可操作提示。
- 通讯录接口仅管理员可调用，新增员工默认没有财务数据权限。
- 已添加员工可以移除本应用授权并重新授权，企微通讯录记录始终保留。
- `npm run check`、`node --check public/app.js`、`npm test`、`npm run check:deploy` 全部通过。
- 生产健康检查返回新版本，服务与备份保持正常，旧版本可回滚。
