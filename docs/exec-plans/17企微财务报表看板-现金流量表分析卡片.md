# 17 企微财务报表看板：现金流量表分析卡片

## 目标

在现金流量表页面右上方增加与资产负债分析一致的关键数据入口。弹窗左侧以页签切换“钱的来源 / 钱的去向”原序项目金额表，右侧同步展示可交互环形图；点击表格、色块或标签时联动突出并显示金额和占比。

## 数据契约

- 只读取当前公司、期间、当前已发布现金流量表的原始上传数据，不建立人工维护副本。
- 以“累计现金收支明细”标题及“增减项 / 项目 / 金额”表头为语义锚点，不依赖固定行列。
- “期初、加、增加、流入”归入来源；“减、减少、流出”归入去向。项目名称保持原文，未知或新增项目仍保留。
- 金额兼容数值、千分位、元、括号负数和短横线；来源和去向图表统一按资金规模的绝对值计算占比。
- 分别保留源表合计和逐项合计；缺少分析区、表头或合计时返回明确提示，不复用其他月份数据。
- 接口每次绑定当前发布批次并禁止缓存；弹窗打开、手动刷新、每 60 秒和页面恢复可见时重新读取。
