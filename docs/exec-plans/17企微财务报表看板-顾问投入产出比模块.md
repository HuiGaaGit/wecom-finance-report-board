# 顾问投入产出比模块 ExecPlan

## 目标

在“桉侨集团”范围新增“顾问投入产出比”模块，按月、按顾问汇总投入与预计营收，并保留工资表、营收明细表和各公司序时账的来源链路。

## 数据口径

- 基本工资、提成：来自集团范围当月已发布的“每月工资表”。工资表姓名是顾问主档。
- 人员费用：来自当前员工有权查看的各公司当月已发布序时账；只取销售费用、管理费用中摘要或科目明确包含顾问姓名的非结转分录，排除工资、薪酬、提成，避免重复。
- 预计营收：来自集团当月已发布营收统计文件“总营收明细表”的“签约顾问/渠道”“预计营收”“业绩归属”列。
- 投入合计 = 基本工资 + 提成 + 人员费用；投入产出比 = 预计营收 / 投入合计。
- 缺失来源不补零、不复用其他期间；无法唯一匹配的姓名单列为待匹配。

## 实施步骤

1. 新增 `payroll_statement` 上传类型、工资表结构识别与原始行保存。
2. 扩展营收统计解析，保存“总营收明细表”顾问产出行。
3. 新增顾问姓名归一、序时账费用归集和集团分析接口。
4. 新增独立权限、集团导航模块、来源说明、汇总卡片、投入产出表和明细弹层。
5. 增加工资/营收/序时账组合回归，验证权限、空态、姓名匹配和重复费用排除。
