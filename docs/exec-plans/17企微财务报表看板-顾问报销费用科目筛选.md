# 顾问报销费用二级科目筛选实施计划

## 目标

将顾问投入产出模块中的“人员费用”统一调整为“报销费用”；提成默认不计入投入；报销费用标签提供当前期间已匹配费用二级科目的下拉多选，并让选择结果同步驱动明细列、投入合计、投入产出比、平均投入产出比和地区汇总。

## 数据口径

- 数据继续只来自当前员工已授权公司、当前期间已发布序时账中的销售费用和管理费用，继续排除工资、薪酬、提成及结转分录。
- 二级科目取“销售费用/管理费用”后的第一段，例如“销售费用-差旅费-机票”归为“差旅费”。
- 下拉只列示当前月份已经唯一匹配到可见顾问、且金额非零的二级科目；同名二级科目跨公司和费用大类合并展示，金额仍按顾问明细精确汇总。
- 原始费用明细和上传报表保持不变；科目勾选只影响浏览器当前视图，不写回数据库。

## 实施步骤

1. 后端为每条顾问费用明细补充规范二级科目，并向顾问分析响应返回可见人员范围内的二级科目列表、金额和明细数。
2. 前端把提成默认状态改为未选择，把“人员费用”统一重命名为“报销费用”，按当前期间初始化为全部二级科目已选。
3. 报销费用标签增加独立下拉箭头；菜单支持逐项勾选、全选、清空，并实时重算报销费用、投入、比率、平均值、地区汇总、筛选和排序。
4. 补充接口与纯前端计算回归，验证跨费用大类的同名科目合并、科目选择重算和提成默认关闭。
5. 完成桌面与 390px 手机页面验收，升级至下一补丁版本，固定候选包并按生产备份、Docker 全测、受控切换和回滚流程发布。

## 验收标准

- 首次进入模块时基本工资、报销费用、投流消耗费用已选，提成未选。
- 报销费用下拉显示当前月份所有已匹配二级科目；取消某科目后相关金额立即从报销费用及所有衍生指标中扣除。
- 关闭整个报销费用标签时该列和筛选项隐藏，但下拉仍可查看或调整二级科目选择。
- 下拉没有撑宽页面，桌面和手机均能完整操作；普通表头筛选及管理员名单设置不受影响。
- 自动测试、语法检查、部署检查、浏览器控制台、数据库完整性和生产健康检查全部通过。

## 风险与回滚

- 科目名称格式异常时只归为“未分类”，不得猜测跨层级名称。
- 本轮不做数据库迁移；回滚恢复上一镜像和源码即可，数据库完整时不得覆盖现有业务数据。
- 发布必须保留财务专用企微授权、目录同步 systemd 单元、数据卷权限和其他项目现状；任一步异常立即停止并回滚。
