# 17企微财务报表看板：公司卡片长按排序

## 目标

首页公司卡片支持拥有全部公司范围的权限管理员长按整张卡片拖动排序，不增加手柄；保存后的公司顺序对所有员工生效，普通员工仍只进行单击选择。

## 交互与权限

- 管理员按住卡片约 460 毫秒后进入拖动态。
- 拖动态生成跟随指针的卡片影子，原位置保留占位，经过其他卡片时平滑换位。
- 未达到长按时间的单击仍选择公司；移动手势超过阈值时取消长按，避免手机滚动误触。
- 只有同时具备权限管理能力和全部公司范围的管理员可以保存全局顺序。
- 普通员工不显示手柄或拖动态，只按管理员保存的顺序过滤展示其授权公司。

## 实施范围

1. 新增全局公司顺序表及幂等补齐逻辑。
2. 启动接口按全局顺序返回公司，并新增管理员保存接口。
3. 首页增加长按、指针跟随、FLIP 换位与保存反馈。
4. 增加接口、权限和前端静态回归测试，更新版本与 README。

## 验证

- `npm run check`
- `node --check public/app.js`
- `npm test`
- 本地检查短按选择、长按抬起、拖动换位、刷新后顺序保留、普通员工无拖动能力及手机滚动不误触。

## 回滚

移除公司顺序接口和首页长按绑定，恢复按公司键排序；保留 `company_display_order` 表不会影响报表或上传数据。
