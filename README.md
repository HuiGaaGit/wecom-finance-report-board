# 桉侨集团财务报表看板

版本：`1.1.25`
生产环境继续使用 `https://anqiaoyiminxq.com/platform/finance/`，复用桉侨小Q现有企微登录但不接收财务正文。财务页面只在建立会话时读取小Q现有短期 access token，不读取或刷新 refresh token；财务服务动态校验 `admin`、`general_manager`、`finance` 三个组并换取 15 分钟、Path 限定为 `/platform/finance` 的 HttpOnly 会话。旧财务自建应用和独立企微 OAuth 已停用，财务模块不连接 AQLLM 数据库或数据卷。

同域名路径可以实现文件、容器、网络、日志和接口的强隔离，但不是浏览器安全边界：小Q页面脚本与财务页面具有相同 Origin，根作用域 Service Worker 也可能覆盖财务路径。若需要阻止同源前端脚本、XSS 或 Service Worker 读取财务响应，必须使用独立 Origin 或独立服务器。

企业微信工作台 H5 财务报表展示首版。当前包含本地演示身份切换、八类财务报表的独立授权、公司与期间范围、历史版本、图表、原始资料上传和权限管理纵向切片。

## 当前首版能力

- 财务资料与同服务器小Q采用三层隔离：专用 `20117:20117` 容器用户和 `0700/0600` 数据权限；独立 Docker 网络、回环端口、无 Docker Socket/共享卷检查；同源财务路径严格 CSP/来源校验/无缓存，并在 Nginx 拒绝回环、同机公网和私网服务端来源，同时关闭访问日志、请求/响应缓冲和代理缓存。财务后台访问小Q时仅允许三个固定身份接口的无正文 GET 请求。每月工资表被固定为内部敏感数据源，不授予任何角色通用报表范围，也不提供 raw、summary、detail、versions 或 export 整表接口。
- SQLite 一致性备份和异机备份状态文件统一按 `0600` 创建，与运行时隔离检查保持一致；定时备份完成后不会再使生产隔离验收失效。
- 管理员侧栏新增“浏览日志”：统一记录全体员工的页面浏览、报表与分析数据访问以及上传、发布、授权等操作；可按人员、浏览/操作类型、动作、模块、公司、期间、起止日期和关键词组合筛选，支持分页、展开详情、全选与勾选批量删除。普通员工不显示入口且管理接口拒绝访问，删除日志的动作自身继续留痕。
- 桉侨集团范围新增财务人员专用“各公司往来校验”：按同期间七家公司已发布科目余额表形成 21 个唯一双边组合，以应收账款、其他应收款减应付账款、其他应付款计算净往来，主账、调整和广宣费/投流推广分别列示；矩阵和异常表识别资料缺失、主体待映射、单边挂账、方向冲突、金额差异及余额方向异常，默认仅看异常。点击组合可查看双方科目余额，拥有独立明细权限时继续读取双方序时账且排除结转分录；未授权公司和期间由后端过滤，特殊名称不会自动算作一致。

- “待处理发布”在发布或删除完成后强制以无缓存请求重新读取当前筛选结果，并用请求序号丢弃较慢的旧响应；操作进行中会锁定同页发布/删除按钮，防止重复提交。页面版本与后台运行版本不一致时会停止数据操作并明确要求重启服务，避免新前端连接旧后台后继续展示已处理记录。
- 上传成功后自动切换到“待处理发布”，并把上传记录筛选同步到本次实际写入的公司和月份；上传校验自动纠正地区或期间时，新生成的已校验批次也会立即显示，不再被进入页面时的旧筛选条件隐藏。

- 顾问投入产出明细支持“基本工资、提成、人员费用”投入标签自由组合，取消标签时对应表格列、筛选项与导出字段同步隐藏，标签直接决定投入合计和投入产出比；明细表不展示来源列，每个可见表头均可筛选和升降序排序，指标卡与 CSV 导出同步采用当前标签、筛选和排序结果。功能区会自动避让右上角折叠按钮与管理员拖动手柄。
- 顾问投入产出模块顶部新增可点击的“顾问平均投入产出比”卡片，按当前投入标签计算所有有投入顾问个人比率的算术平均；弹层同时按业绩归属展示各地区的投入、预计营收和投入产出比，同一顾问跨地区时按各地区预计营收占比分摊投入，避免重复计入。

- 桉侨集团范围新增“顾问投入产出比”：工资表以“部门名称含顾问”形成顾问主名册，非顾问部门人员不进入明细；投入读取顾问当月基本工资、提成及各授权公司序时账中明确归属于顾问的销售/管理费用，排除工资提成和结转重复。产出只读取营收统计文件“总营收明细表”中与所选期间一致的“月份、签约顾问/渠道、预计营收、业绩归属”，并且仅归入工资顾问名册，避免渠道或其他人员混入。来源区展示顾问部门、纳入及排除人数和真实字段映射。
- 每月工资表会按上传时选择的会计期间定位对应工资工作表，兼容 `202607工资表`、`2026年7月工资表`、`26年7月工资表` 等命名；“部门”现为必需字段，姓名支持“中文姓名/姓名”，基本工资优先读取精确“基本工资”字段，提成优先读取“本月提成”且不混入“往期提成”，同时识别“入职日期/入职时间”等字段。当月入职顾问在姓名旁显示“新”标记，点击可查看标准化入职日期。文件仅含其他月份工资页时会明确拦截，不再误取第一个历史月份。
- 顾问投入产出页面提供“刷新数据”按钮，停留页面时每 60 秒检查一次工资、营收统计表及各公司序时账的最新发布版本，浏览器标签恢复可见时立即检查；数据源版本签名变化后自动重绘。旧发布批次若缺少新版营收明细结构或工资入职日期字段，会从保留的原始上传文件一次性重新解析并缓存，不要求重新上传。

- 左侧“资产负债表”前新增“财务数据简报”：按当前公司与期间自动从已发布的资产负债表、利润表、集团合并利润表及营收利润口径文件联合取数，生成月度收支文字；预计营收可用地区简称稳定匹配合并文件中的完整主体名称，并兼容千分位及带“元”的金额文本；营业收入、营业成本、销售费用、管理费用和财务费用直接取利润表总数，广宣费保持单独归集展示；集团口径自动汇总各公司账户余额与广宣费，来源不齐时明确显示缺失项且不按零处理。
- 财务数据简报进入页面时立即读取最新已发布数据，页面停留期间每 60 秒自动刷新，浏览器标签恢复可见时立即补刷新，并提供与公司、期间筛选控件保持同一水平行的人工“刷新数据”按钮；自动刷新状态仅保留无障碍提示，不再在按钮下方显示更新时间说明，刷新失败时保留上一版内容并自动重试。广宣费仅读取相应月份科目余额表末级相关科目的“本期发生额—借方”，不抵减贷方且不回退序时账；金额直接列示在销售费用原文字说明中，不再显示额外来源明细。
- 首页点击“开始浏览报表”后，按当前员工可见的财务模块顺序进入第一个模块；默认优先进入“财务数据简报”，无简报权限时回退到首个可见财务报表，不会误跳到上传、分析或管理模块。
- 旧数据库升级时会一次性消除模块排序并列值并把“财务数据简报”归位到“资产负债表”之前；之后管理员保存的完整全局模块顺序继续持久化，刷新和重新登录后保持一致。
- 资产负债表、利润表、桉侨集团合并利润表、（营收利润口径）合并利润表、营收统计表、现金流量表、科目余额表和序时账。
- “桉侨集团”作为独立查看范围；集团范围显示“桉侨集团合并利润表”和“集团合并利润趋势图”，公司范围不混入集团报表或集团分析。左侧合并利润表父模块可展开同一集团文件内的各子公司完整名称，点击子项直接查看对应工作表，金额不跳转序时账；合并利润表自动提取正式正文 B1:E36，并校验集团金额与公司分表逐行加总一致，报价单和毛利辅助区不进入报表模块。
- 集团范围新增“营收统计表”父模块，左侧展开集团维度、单独直客维度、单独渠道维度；页面内分别切换 B1-B3、B4-B6、B7-B8 二级统计表。数据动态读取用户上传文件中的 `数据统计汇总表（mia）`，保留金额、占比、项目数量和口径提示，只允许发布到桉侨集团范围。
- 集团范围新增独立“（营收利润口径）合并利润表”，只读取所选集团期间专属文件的 B1:H36 正式正文，展示本年累计、本期、当月调整、累计调整和说明，并在净利润行收口；项目预算毛利、销售额等正文后的辅助区不展示，所有金额及调整数均不可下钻。
- “（营收利润口径）合并利润表”父模块可展开广州、深圳、成都、南京、长沙、青岛、北京七家完整公司名；子项直接读取同一已发布集团文件的对应工作表，标题、编制单位和集团分表提示统一显示完整主体名称。
- 集团合并利润趋势图按同年度、截至当前期间的已发布合并利润表取数，包含营业收入与营业成本、期间费用、净利润三张趋势图；期间费用同时展示销售费用、管理费用、财务费用及合计，未上传月份不补零、不展示，也不读取其他公司数据。
- 手机端原始报表保留可读列宽并在表格区域横向滑动，避免金额和表头被强制挤压；编制信息在窄屏下自动分行。
- 桌面端原始报表的标题、编制信息、来源信息、表头和单元格字号会按报表容器宽度平滑缩放；科目余额表达到最低可读宽度后改为表内横向滚动，避免数字与相邻列重叠。
- 手机端点击模块时立即切换选中态和页面，不再执行按钮、页面淡入或导航滑行动画；快速连续切换报表时仅最后一次请求允许渲染，避免旧响应覆盖当前页面。
- 桌面端左侧导航固定为完整宽度，报表宽表、分析网格及管理工作台的超宽内容限定在右侧模块内部滚动，不再挤压导航或撑宽整个页面。
- 每张报表独立配置“汇总”和“明细”权限。
- 权限按员工/角色、公司范围、期间范围和查看/导出动作计算。
- 每次导入保留数据版本，支持历史版本列表和版本切换。
- 用户每次在企微应用中上传的文件是唯一事实源；上传批次不可覆盖，支持校验、发布和历史追溯。
- 各账套助手只提供原始报表模板、字段和格式参考，不自动同步或覆盖用户上传数据。
- 资产负债表、利润表、现金流量表、科目余额表按原始财务报表样式展示；资产负债表仅期末余额提供下钻，年初余额锁定为对比数据；现金流量表兼容“年度累计”“本年累计金额”和“2026年累计”等年度累计表头，仅本期金额提供下钻并读取同期间隐藏的“现金流量表底稿”，底稿明细不展示底稿备注，年度累计与前期累计金额仅作对比展示、不可点击。
- 公司名称、编制单位和往来主体名称均按当前公司及上传工作表动态读取；当前公司及期间未上传时，各类报表和分析模块统一显示“暂无数据”，不复用其他公司的模板、金额或明细。
- 默认入口为“首页”，页面中央使用公司卡片和月份按钮选择查看范围；报表和分析模块只读该范围并以纯文字显示，防止同一页面组合出不同账套数据。
- 首页公司卡片按当前账号的公司数据范围过滤，未授权公司不会出现在卡片列表或可用期间数据中。
- 拥有全部公司范围的权限管理员可在首页长按整张公司卡片进入拖动态，无需额外手柄；拖动时浮动卡片跟随指针、其他卡片平滑让位，保存后的全局公司顺序对所有员工生效，普通员工只读取其授权公司对应的排序结果。
- 首页只展示当前员工权限范围内确有已发布数据的期间；首次进入、切换公司或切换员工时默认选中最新期间，用户手动选择历史期间后保持该选择。
- 顶部员工、公司、期间选择器及全局卡片、面板采用统一的半透明毛玻璃层次、清晰焦点态和克制动效；五张财务原始报表的普通区域采用透明底色并与页面背景融合，灰色分组行、黄色合计行等特别标色仍保持原样。
- 原始报表自动裁掉最后一个有效数据行之后的连续空白格式行，保留报表中间用于分组的空行；利润表固定在最后一个“净利润”行收口，不再把下方空行或辅助计算表误当成报表正文。
- 原始三张报表的表头期间以已校验上传范围为准；Excel 日期序号会在导入时规范为年月，并清除合并单元格中不可见的历史期间残值，避免正确的“2026年7月”被误显示成旧月份。
- 点击金额后进入独立“序时账明细清单”页面，不在原报表下方追加明细区域；下钻始终读取同公司、同期间已发布的序时账，即使报表与序时账分批上传也能正确匹配。利润表各科目下钻自动排除“结转损益、损益结转、结转本年利润、期末结转”等期末结转整张凭证，原始序时账仍完整保留。
- 序时账明细仅展示凭证号、科目名称、摘要和金额；摘要自动换行并适配单页宽度。
- 权限管理采用“小Q授权成员选人 → 套用角色分组预设 → 员工完整权限树微调 → 保存”的工作流；角色只提供默认值，个人增删不会污染同角色的其他员工。
- 权限管理升级为可扩展“权限中心”：员工授权采用成员列表与编辑区两栏布局，编辑区拆为快速配置、模块权限和高级设置；模块权限按财务报表、经营分析、报表上传和系统管理显示紧凑动作矩阵，支持搜索、状态筛选、分类批量操作和恢复预设。生效摘要改为按需抽屉，底部显示未保存变更、取消和保存；手机端使用员工列表进入员工详情的两级流程，不再把名单、完整权限树和摘要纵向堆叠在同一页。
- 权限中心的角色预设页只读展示现有模板及使用人数，授权审计页仅列出接口可核验的员工档案状态，全局设置集中管理员工水印；本阶段仍保存完整 `permissionKeys`，不改变现有数据库、角色基线和最终生效权限。
- 员工数据范围新增“全部不可见”：未配置授权的员工默认不返回任何公司、可用期间或财务数据模块；管理员也可显式保存零公司范围。该管理选项不会出现在员工端，员工首页只显示无可查看数据的通用空状态；即使另有上传权限，服务端仍会拒绝零范围账号向任意公司上传、校验或发布数据。
- 内置“地区总经理”预设，默认浏览资产负债表、利润表、现金流量表、资产净额分析、主营业务分析和费用分析；首页为所有员工固定入口，科目余额表、序时账、上传和系统管理默认关闭。
- 每名员工独立保存公司/地区范围、起止期间、报表浏览/明细/导出、分析、上传和系统管理权限，以及科目名称、借贷方向和完整分录显示偏好。
- 资产净额、主营业务和费用分析中各业务表格与图表均作为所属分析页下的独立子模块权限；关闭子模块后，启动接口、分析数据接口和页面布局会同步裁剪，子权限不能脱离页面权限单独生效。
- 管理员分析布局继续写入独立持久数据库；升级只把新增板块追加到现有顺序末尾，并一次性整理历史并列序号，不按版本默认值覆盖管理员已保存的相对顺序。
- 报表及分析切换取消同步强制回流并丢弃过期分析响应；分析拖动按动画帧合并换位计算，以合成层完成平滑让位和轻回弹，受限可见板块保存时不会破坏全局完整顺序。
- 权限树显示相对角色预设的“已追加/已移除”差异和分组半选状态；保存前展示最终有效权限、数据范围和高风险管理权限摘要。
- 权限管理员可把一个员工的角色预设、全部个人微调、公司期间范围和明细偏好完整复制给另一名企微员工，仅替换被授权人。
- 权限设置中的“全部公司”使用统一通配范围保存，选中后自动覆盖单家公司选择，不再被误判为无效公司范围。
- 权限管理员可移除已添加员工在本应用中的全部授权；该操作不删除企微通讯录人员，员工之后仍可重新授权，同时禁止管理员移除自己以避免权限管理被锁死。
- 上传统一在“上传报表”模块进行，上传公司与会计期间使用独立选择器，不受首页查看范围锁定；拥有全部公司范围的权限管理员可在公司选择器中新增公司并立即选中；支持各类报表分别选择、把单个 Excel/JSON 文件直接拖到对应报表卡片，或拖动归集文件夹自动识别；拖到卡片时直接接收文件，只有点击“选择文件”才打开文件选择框。
- 上传提交会以当前上传页内的公司、期间和文件控件为唯一状态源，并在发送前校验公司、期间、报表位置、文件格式、文件大小与浏览器读取结果；文件状态失效或读取为空时会要求重新选择，后端也会明确返回具体缺失或失效字段，不再只显示笼统的“均为必填”。
- 上传页提供“桉侨集团合并利润表”独立入口，兼容“集团利润表”“桉侨集团合并利润表”等工作表/文件名；文件自动匹配“桉侨集团”和期间，禁止误归属到单家公司。
- 上传页提供“（营收利润口径）合并利润表”独立入口，自动识别“营收利润口径/营收口径”文件名与集团工作表，只允许发布到桉侨集团范围；标准合并利润表、营收利润口径表和营收统计表分别保留版本，不互相复用数据。
- 待上传文件可在对应报表卡片内逐项“移除”，也可在选择区一键“清空已选”；清除只作用于尚未提交的本地选择，不影响上传历史和已发布数据。
- Excel 上传按真实非空单元格自动裁剪尾部空白行列，避免 `A1:P1048576` 等异常使用范围被完整展开；有效范围最多 200000 行、256 列且不超过 3000000 个单元格，超限时错误会明确指出工作表名、有效范围及限制，自动裁剪成功也会写入上传结果和校验记录。
- 上传历史支持勾选并批量删除未发布记录；有发布权限的管理员也可撤回并删除当前发布，系统自动恢复最近的上一上传版本，如无上一版本则回到“暂无数据”；被替换的历史版本仍锁定保留，避免绕过回滚链路直接破坏财务追溯。
- 上传历史支持勾选多条已校验记录后批量发布；系统会先完整校验权限、状态、公司、期间、报表类型和版本快照，再以单个事务统一发布，避免出现部分成功。
- 上传记录管理支持按公司、会计月份、报表类型和文件名筛选，并分页展示；“待处理发布”与“发布版本”拆为两个状态子模块，跨范围查看时按公司和月份分组，批量发布、当前版本撤回和锁定历史版本互不混杂。
- 支持直接上传包含三份正式内部报表和隐藏科目余额表的汇总财务报表文件；系统按工作表自动拆分为独立报表批次，隐藏工作表照常读取。
- 工作表识别兼容任意月份前缀，例如“5月科目余额表”“5月序时账”及“2026年5月利润表”；选择上传地区或期间时会与已选文件提示复核，上传时由后端按文件名、公司清单和工作表名称再次校验，不一致时可明确切换后继续。
- 发布前集中展示文件、地区、期间和报表类型供最终确认；发布接口会再次校验文件中的地区与期间线索，发现归属错误时阻止发布并要求按正确范围重新上传。
- 序时账导航页仅显示日期、凭证号、摘要、科目编码、科目名称、借方金额和贷方金额，摘要与科目名称自动换行。
- 序时账明细清单将借贷方向单列显示；权限管理员可按角色设置显示或隐藏该列，金额列始终仅显示数值。
- 权限管理员可按角色设置跳转明细时是否展开完整分录；隐藏后只展示所点击科目的对应分录行。
- 首页不展示财务指标，专注于公司与会计期间选择；公司采用带数据状态的卡片单选，期间按年份分组为月份按钮，并在底部集中确认当前范围后进入工作台。
- 资产净额分析按资金管理口径展示货币资金、内部往来净额、应收应付净额、核心流动性净额与静态流动性净额；五张核心指标卡采用五等分单行布局，并用构成引导线说明指标关系；页面不再展示现金流量结构图，并新增全年核心流动性净额霓虹趋势图，缺少已发布科目余额表的月份断开留空，不虚构为零。
- 资产净额分析中的集团往来主体保留科目余额表里的完整公司名称；普通往来与“调整”往来按各自明细科目编码独立汇总和下钻，不再用简称模糊匹配，并可从同期间已发布汇总文件内的序时账工作表读取明细。
- “应收应付净额构成”表将逐行口径说明收进可点击的小问号，并可按需向右展开应收账款、其他应收款、应付账款和其他应付款四个构成列；应付类作为减项展示，零值用短横线表示。
- “应收应付净额构成”作为资产净额分析下的独立查看权限，可按员工开启或关闭；无权限时不返回主体构成明细，也不渲染该板块，折叠状态和管理员全局拖动顺序均不能绕过授权。
- 主营业务分析按序时账展示本期项目收入成本明细、项目数量环比和本年毛利月度趋势；趋势图仅保留毛利主线并按毛利自身区间突出态势，非零月份直接标注毛利金额；项目数量采用表格内嵌双条形对比，收入取主营业务收入贷方，成本取主营业务成本借方。项目名称和客户名称均按序时账表头动态定位；客户列为空时可从带订单号的收入摘要识别客户，同一日期、同一凭证只有一个订单号时，摘要漏写订单号的成本行会继承该订单及客户，多订单凭证保持未识别以避免错配；不同模板中的“会计001、会计002”等制单人或审核人编号不会被误识别为业务项目。
- 费用分析按序时账展示销售费用、管理费用二级科目本期/上期及变动率，配套年度月度趋势和本期占比；财务费用按摘要识别银行转账、通联扫码、富友、财付通并匹配手续费和手续费比率。
- 生产权限管理页由小Q管理员同步管理员、总经理和财务组三个成员组，支持按姓名或成员组搜索、查看同步人数与状态，并可手动刷新。
- 权限管理员可直接拖动左侧导航中的六点手柄调整看板模块顺序，顺序持久化并对所有员工生效；权限管理页不再保留重复的模块排序区域。
- 默认导航顺序将“上传报表”放在“权限管理”正上方；既有环境只迁移一次，迁移后管理员仍可继续拖动调整并全员生效。
- 管理员可直接拖动资产净额分析、主营业务分析、费用分析和集团合并利润趋势图中的指标卡、表格及图表板块；拖动手柄采用独立绝对定位覆盖层，不参与模块宽度、网格轨道或内容排版，悬浮时显现，数据来源固定不参与拖动；换位采用 FLIP 动画，被挤开的板块平滑让位并轻微回弹；四个页面分别保存全局布局，普通员工只读取布局且不显示拖动手柄。
- 四个分析页面的每个子模块均提供独立折叠/展开按钮；折叠状态按当前员工和分析页面保存在本机，切换页面或刷新后继续保持，且不会影响管理员拖动排序。
- 首页固定在侧栏首位且不参与权限或拖动排序；其余模块按当前员工、公司和期间的权限过滤，未授权报表不会展示。
- 支持 `demo` 与 `platform` 两种身份模式：本地继续使用演示员工切换，生产环境复用小Q企微登录并忽略演示身份请求头；首次进入的授权员工默认没有财务数据权限，由财务权限管理员后续配置。
- 正式环境使用独立 Docker Compose、独立网络和 SQLite 持久目录，由主站 Nginx 反向代理。
- 正式地址为 `https://anqiaoyiminxq.com/platform/finance/`；静态资源、财务 API 和短期会话 Cookie 均限定在 `/platform/finance` 下。
- 页面持续展示ICP备案号“粤ICP备2022138475号-5”并链接工信部备案查询平台；桌面端位于侧栏底部，手机端位于页面底部。
- 顶部仅保留当前员工姓名和企微真实部门名称，不再展示认证状态或角色徽标；管理员可全局开启员工水印，在五张财务报表和序时账明细页重复显示员工、部门、公司及期间，水印不阻挡表格操作且不写入上传数据或导出文件。
- 顶部右上角提供轻量分享箭头，只复制不含登录凭证的正式地址供用户粘贴到企微聊天；接收人打开后仍需通过小Q企微登录，并按自己的成员组和财务数据权限显示。
- 报表底部的明细跳转提示与当前员工的明细权限联动；没有查看明细权限时不显示提示，金额也不呈现为可点击入口。

## 异机备份

新生产服务器每天北京时间 `00:15、08:15、16:15` 先生成 SQLite 一致性快照，再通过 SSH/rsync 把数据库备份、上传原件和恢复配置增量推送到旧服务器专用目录。旧服务器不运行当前项目，只作为隔离备份节点；同步不使用 `--delete`，上传原件长期保留，数据库与配置快照保留 90 天。实施、验证和恢复说明见 `docs/PRODUCTION_OPERATIONS.md` 与 `docs/exec-plans/17企微财务报表看板-新旧服务器异机备份.md`。
